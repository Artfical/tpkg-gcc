GCC 15.3.0 for tOS (revision 3)
==============================

Built from the release tarball (gcc-15.3.0.tar.xz beside this package), unmodified, for x86-64 Linux: C and C++, as a native compiler that uses the binutils package's as and ld and the glibc-dev package as its sysroot (--prefix=/system/pkg/gcc --with-sysroot=/system/pkg/glibc-dev/sysroot --with-as=/system/pkg/binutils/bin/as --with-ld=/system/pkg/binutils/bin/ld --enable-languages=c,c++ --disable-multilib --disable-bootstrap --enable-default-pie). The compiler is linked statically with GMP, MPFR, MPC and ISL (their sources are beside this package too; GMP, MPFR and MPC are LGPL, ISL is MIT).
lib/gcc/x86_64-pc-linux-gnu/15.3.0/specs differs from GCC's own in making programs link libgcc and libstdc++ statically (they run on tOS's older system libstdc++) and in listing the folders of the library packages (zlib-dev, openssl-dev, liblzma-dev, ncurses, readline, libffi, bzip2, sqlite, expat, pcre2, libyaml, and the runtime packages openssl and zlib) as places for headers (-idirafter), libraries (-L) and run-time search (rpath); a folder that is not installed is ignored. License: GPL-3.0 or later with the GCC Runtime Library Exception (LICENSE, LICENSE.RUNTIME).

Revision 3: the specs file also lists the folders of the qt6-base, sdl2, xorg, xcb-libs, xcb-util, xkbcommon and fontconfig packages (headers, -L, run-time search and link-time search), so that `g++ prog.cc -lQt6Widgets -lQt6Gui -lQt6Core` and SDL or X11 programs build without extra flags (the Qt headers are in /system/pkg/qt6-base/include/QtCore and so on: use qmake or cmake, or add -I). A folder that is not installed is ignored.
